# Speed Read

*Read this in other languages: [English](#english), [Türkçe](#türkçe)*

---

## English

A web application and Chrome extension designed to improve reading speed using the RSVP (Rapid Serial Visual Presentation) technique.

### Features
- **RSVP Reading:** Displays words one by one to eliminate the time lost during eye movements.
- **Optimal Recognition Point (ORP):** Highlights the middle letter of each word in red for faster visual perception.
- **Smart Pacing:** Starts the first 5 words at a slower pace to help the eyes adjust. Automatically pauses at punctuation marks.
- **Context Preservation:** Shows the 3 preceding and 3 succeeding words faintly to maintain sentence context.
- **Input Methods:** Supports manual text pasting, PDF uploads, and extracting article text directly via Wikipedia links.
- **Controls & Stats:** Includes keyboard shortcuts for easy control. Generates reading time and word statistics after each session.

### Installation & Usage

#### Web (PWA) Version
1. Clone the repository:
   ```bash
   git clone [https://github.com/canfidan/Speed-Read.git](https://github.com/canfidan/Speed-Read.git)
   ```
2. Open `index.html` in your browser.
3. Click the install icon in the address bar to use it as a Progressive Web App (PWA).

#### Chrome Extension
1. Download the project files.
2. Navigate to `chrome://extensions/` in your Chrome browser.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the downloaded project directory.
5. Select any text on a webpage and launch the extension to start reading.

## Türkçe

RSVP (Rapid Serial Visual Presentation) tekniğini kullanarak okuma hızını artırmayı hedefleyen bir web uygulaması ve Chrome eklentisi.

### Özellikler
- **RSVP Okuma:** Göz hareketlerinden kaynaklı zaman kaybını önlemek için kelimeleri tek tek gösterir.
- **Odak Noktası (ORP):** Algılamayı hızlandırmak için kelimenin ortasındaki harf kırmızı renkle vurgulanır.
- **Akıllı Akış:** Okumaya başlandığında gözün alışması için ilk 5 kelime yavaş geçer. Noktalama işaretlerinde doğal duraklamalar yapar.
- **Bağlam Koruması:** Cümlenin gidişatını kaybetmemek için okunan kelimenin 3 öncesi ve 3 sonrası silik olarak ekranda kalır.
- **Girdi Yöntemleri:** Manuel metin girişi, PDF yükleme ve Wikipedia linki üzerinden doğrudan metin çekme.
- **Kontrol & Raporlama:** Klavye kısayolları ile kontrol edilebilir. Okuma bitiminde süre ve kelime istatistiklerini raporlar.

### Kurulum ve Kullanım

#### Web (PWA) Olarak Kullanım
1. Repoyu klonlayın:
   ```bash
   git clone [https://github.com/canfidan/Speed-Read.git](https://github.com/canfidan/Speed-Read.git)
   ```
2. `index.html` dosyasını tarayıcınızda açın.
3. İsteğe bağlı olarak adres çubuğundaki yükle butonuna tıklayarak cihazınıza PWA olarak kurabilirsiniz.

#### Chrome Eklentisi Olarak Kullanım
1. Proje dosyalarını bilgisayarınıza indirin.
2. Chrome'da adres çubuğuna `chrome://extensions/` yazarak uzantılar sayfasına gidin.
3. Sağ üst köşeden "Geliştirici modu"nu aktif hale getirin.
4. "Paketlenmemiş öğe yükle" butonuna tıklayın ve indirdiğiniz proje klasörünü seçin.
5. Eklentiyi kurduktan sonra herhangi bir web sayfasında metni seçin ve eklenti üzerinden hızlı okumayı başlatın.
